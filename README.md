# Java Day 33 - Sum of Elements at Odd Indexes

This Java program calculates the sum of array elements stored at odd index positions.

## Example

Array:
```text
[10, 20, 30, 40, 50, 60]
```

Odd indexes: `1, 3, 5`

Output:
```text
Sum of elements at odd indexes = 120
```

## Concepts Used

- Arrays
- `for` loop
- `if` statement
- Modulus operator `%`
- Array indexing
- Sum calculation

## How It Works

The program loops through the array and checks whether each index is odd. If the index is odd, its element is added to the sum. Finally, the program displays the total.
